# Frontend Redesign Plan — Premium SaaS UI

## Design Decisions (Locked)
- **Sidebar:** Collapsible with icon-only mode (68px) ↔ expanded (248px). localStorage persistence.
- **Primary color:** Keep indigo/violet (`245 75% 59%`). Refine, don't replace.
- **Intensity:** Polish and refine. Keep aurora background, glassmorphism, animations. Improve spacing, typography, shadows, hover states across the board.

## Constraints
- **DO NOT** rebuild, modify backend, change DB schema, or remove existing functionality
- **ONLY** redesign the frontend visually
- Keep all existing pages and business logic intact
- Implement ONE section at a time; stop and wait for approval after each

## Phase 1: Design System Foundation

**Goal:** Establish the new visual language that all subsequent phases build on.

### Files to modify:
- `tailwind.config.ts` — New color tokens, shadows, animations, font config
- `src/app/globals.css` — New CSS custom properties, utility classes, animations
- `components.json` — Update if needed for shadcn/ui compatibility

### Design tokens:
- **Color palette:** Keep current indigo/violet primary (`245 75% 59%`), refine neutrals. Near-white bg (`#fafafa`), card bg (`#ffffff`), border (`#eaeaea`). Improve success/warning/error semantic colors for better contrast
- **Typography scale:** Inter for Latin, Noto Sans Bengali for Bangla. Tighter letter-spacing on headings (`-0.025em`), improved line-height ratios (1.5 body, 1.2 headings)
- **Shadow system:** 5-tier (xs, sm, md, lg, xl) — subtle, multi-layered, dark-mode aware. Refine existing 4-tier system
- **Border radius:** Keep current scale, refine `--radius` base to `0.625rem` for slightly softer corners
- **Spacing:** Ensure consistent 4px grid, refine component padding/margin
- **Transitions:** Standardize on `200ms cubic-bezier(0.22, 1, 0.36, 1)` for micro-interactions

### New utility classes:
- `.card-premium` — Card with refined shadow, border, hover lift
- `.btn-*` refinements — Smoother transitions, better focus rings
- `.glass-premium` — Refined glassmorphism for overlays
- `.surface-*` — Tiered surface colors (base, raised, overlay)

### Verification:
- `npm run dev` — verify no CSS/build errors
- Visually confirm color tokens work in light and dark mode
